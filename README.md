Nom de l'application 
Description 
Cette application web a été développée dans le cadre du projet final du cours 
420-211 - Application Web. 
L'objectif de l'application est de permettre aux utilisateurs de rechercher et 
consulter des cartes de jeux de one piece a partir du OptcAPI. L'utilisateur peut parcourir 
une liste de cartes, effectuer une recherche par nom, consulter les détails de 
chaque personnages et sauvegarder ses favoris. 
Fonctionnalités principales 
● Affichage d'une liste des personnages sous forme de cartes 
● Recherche d'un personnage par nom 
● Consultation des détails d'une carte (image, nom, prix, etc.) 
● Ajout et suppression de favoris 
API utilisée 
● Nom : OptcAPI
● URL : https://optcgapi.com/api/sets/card/OP01-001/
